## 9.3 能力对照（回顾）

| 目标 | 命令或动作 |
|------|------------|
| 编译 | `forge build` |
| 测试 | `forge test` |
| 模拟脚本 | `forge script ...`（无 `--broadcast`） |
| 本地节点 | `anvil` |
| 私钥 → Keystore | `cast wallet import ...` |
| 链上部署 | `forge script ... --broadcast --keystore ...` |
| 读合约 | `cast call ...` |
| 写合约 | `cast send ... --keystore ...` |

## 9.4 安全提醒

测试网专用密钥与 RPC；勿将真实主网大额资产用于课堂命令；API Key 与 keystore **勿提交公开仓库**。
