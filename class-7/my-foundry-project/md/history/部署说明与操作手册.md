# 部署脚本说明与操作手册

本文面向本仓库 `class-7/my-foundry-project`，说明 **`script/DeployAll.s.sol`** 的作用，以及如何一步步完成编译、模拟与链上广播部署。

---

## 一、脚本位置与部署内容

| 路径 | 合约名 | 行为 |
|------|--------|------|
| `script/DeployAll.s.sol` | `DeployAll` | 在同一批广播交易中依次部署：`Counter`、`Token10000WithCallbacks`、`CallbackReceiverDemo`、`SimpleWallet` |

- **`IERC1363.sol` / `IERC1363Receiver.sol` / `IERC1363Spender.sol`** 仅为接口，**不部署**。
- 脚本文件顶部注释中有可直接复制的 `forge script` 命令。

同目录下还有历史示例（按需使用）：

- `DeployCounter.s.sol` — 仅部署 `Counter`
- `DeployScript.s.sol` — 部署 `Counter` 并 `setNumber(42)`
- `CounterScript.s.sol` — 使用环境变量 `DEPLOYER_ADDRESS` 的写法示例

---

## 二、前置条件

1. 已安装 [Foundry](https://book.getfoundry.sh/getting-started/installation)（`forge`、`cast`、`anvil` 可用）。
2. 在项目根目录执行编译：

```bash
cd /Users/evan/web3Code/learn-chain-class-demo/class-7/my-foundry-project
forge build
```

3. （可选）在根目录配置 `.env`，**勿将私钥提交到 Git**：

```bash
PRIVATE_KEY=0x你的测试网私钥
SEPOLIA_RPC_URL=https://你的Sepolia_RPC
```

`foundry.toml` 中 `[rpc_endpoints] sepolia` 会读取 `SEPOLIA_RPC_URL`。

---

## 三、核心概念（简要）

- **`forge script`**：执行 Solidity 脚本里的 `run()`。
- **`vm.startBroadcast()` ~ `vm.stopBroadcast()`**：其中的 `new 合约()` 在带上 **`--broadcast`** 且提供签名方式时，会作为真实交易发送；**不带 `--broadcast`** 时一般为本地模拟，便于先看 Gas 与是否 revert。

---

## 四、操作：本地 Anvil 部署

### 步骤 1：启动本地区块链

```bash
anvil
```

默认 RPC：`http://127.0.0.1:8545`。

若提示 **Address already in use**，说明 8545 已被占用。任选其一：

- 使用已在运行的节点（继续用 `http://127.0.0.1:8545`），或  
- 换端口启动：`anvil --port 8546`，下面命令里的 `--rpc-url` 改为 `http://127.0.0.1:8546`。

### 步骤 2：广播部署（Anvil 第 1 个测试账户私钥，仅本地）

```bash
cd /Users/evan/web3Code/learn-chain-class-demo/class-7/my-foundry-project

forge script script/DeployAll.s.sol:DeployAll \
  --rpc-url http://127.0.0.1:8545 \
  --broadcast \
  --private-key 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80
```

终端会打印四个合约地址。

### 步骤 3：用 cast 简单验证（示例）

将 `<TOKEN>` 换成输出的 Token 地址：

```bash
cast call <TOKEN> "totalSupply()(uint256)" --rpc-url http://127.0.0.1:8545
```

## 五、操作：仅模拟、不上链

用于检查脚本能否跑通、估算 Gas（不发交易）：

```bash
forge script script/DeployAll.s.sol:DeployAll \
  --rpc-url http://127.0.0.1:8545
```

（不写 `--broadcast`。）

## 六、操作：Sepolia 测试网部署

1. 配置好 `SEPOLIA_RPC_URL` 与**你自己的**测试私钥（不要用 Anvil 默认钥）。
2. 执行：

```bash
cd /Users/evan/web3Code/learn-chain-class-demo/class-7/my-foundry-project
source .env   # 若变量写在 .env 里

forge script script/DeployAll.s.sol:DeployAll \
  --rpc-url sepolia \
  --broadcast \
  --private-key $PRIVATE_KEY
```

合约验证：可在命令中加 `--verify`，并配置 `foundry.toml` 的 `[etherscan]` 与 API Key，详见 [Foundry 文档：验证合约](https://book.getfoundry.sh/forge/deploying#verifying-a-contract)。

## 七、部署顺序与账户关系

在同一轮 `DeployAll` 广播中：

1. **Counter** — 课内计数器示例。  
2. **Token10000WithCallbacks** — 全部初始供应量铸给**当前广播签名账户**。  
3. **CallbackReceiverDemo** — 接收 ETH 与 ERC1363 风格回调演示，可与代币做 `transferAndCall` / `approveAndCall` 联调。  
4. **SimpleWallet** — `owner` 为**创建该合约的交易发送者**（与广播账户一致）。

因此：**代币与 SimpleWallet 的 owner 均为本次部署使用的账户**，便于联调。

## 八、常用命令速查

| 目的 | 命令要点 |
|------|----------|
| 编译 | `forge build` |
| 模拟脚本 | `forge script script/DeployAll.s.sol:DeployAll --rpc-url <RPC>` |
| 上链 | 加上 `--broadcast` 与 `--private-key`（或 ledger/keystore 等） |
| 更多参数 | `forge script --help`（如 `--gas-estimate-multiplier`） |

---

## 九、安全提示

- 主网私钥不要写入仓库；生产环境优先硬件钱包或托管签名流程。  
- 执行前确认 `--rpc-url` 与目标网络、链 ID 一致，避免误发到错误链。  
- 测试网 ETH 仅用于学习实验。

---

## 十、自定义部署范围

若只需部分合约，可复制 `DeployAll.s.sol` 为新文件，删除不需要的 `new ...` 行，并相应修改 `forge script` 中的合约名与路径即可。
