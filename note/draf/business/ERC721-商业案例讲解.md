# ERC-721 商业案例讲解

**一句话**：ERC-721 代表「每一件都独一无二」的数字所有权凭证，适合收藏、身份、门票、域名等**不可互换**资产。OpenSea 等市场能统一展示报价，正是因为大家都遵守同一套 721 接口。

配套演示：`erc-demo/erc721/DemoERC721.sol`（类比「会员 NFT / 数字藏品」）。

---

## 1. 解决什么商业问题

| 商业诉求 | ERC-721 如何满足 |
|----------|------------------|
| 稀缺性与定价 | 每个 `tokenId` 单独定价、拍卖、版税 |
| 品牌与身份 | PFP、会员证、活动入场凭证可公开展示 |
| 二级市场 | 创作者版税（EIP-2981 等）+ 市场撮合抽成 |
| 链上确权 | 所有权记录在链上，便于转让与审计（非链下合同替代） |

## 2. 成熟商业案例

### 2.1 NFT 收藏品与 IP

- **Bored Ape Yacht Club（Yuga Labs）**  
  - **模式**：发售限量 PFP → 持有者可进专属社区、获得后续空投与 IP 商用许可（条款随项目变化）。  
  - **收入**：一级发售 + 二级市场版税 + 衍生 IP。  
- **CryptoPunks（Larva Labs，后被 Yuga 收购）**  
  - 早期 10k 唯一像素头像，奠定「链上稀缺头像」品类。

**商业逻辑**：721 让「第 #1234 号猿」与「#5678 号」在合约层就是不同 SKU，便于炒作叙事与稀有度分层。

### 2.2 交易市场：赚撮合费

- **OpenSea**（及 Blur 等竞争者）  
  - **模式**：挂单/出价 → 成交抽成（如 2.5%）+ 可选创作者版税。  
  - **为何依赖 721 标准**：同一前端可展示任意合规 NFT 合约，降低上架成本。  
  - **竞争维度**：流动性、零费率活动、专业交易者工具、版税政策与品牌合作。

### 2.3 域名与身份

- **ENS（Ethereum Name Service）**  
  - **模式**：用户购买 `xxx.eth`（每个名字对应一个 721 token）→ 可解析到钱包地址、网站。  
  - **商业延伸**：短名溢价、续费、与子域名企业服务。

### 2.4 票务与活动

- **Coachella、NBA Top Shot（早期 Flow 链，概念类似）**、各类 **NFT Ticket**  
  - **模式**：一张票一个 tokenId → 入场核销可链上校验或绑定动态二维码。  
  - **价值**：抑制黄牛需结合 KYC/灵魂绑定；链上部分解决「假票」与二次转售透明。

### 2.5 房地产与 RWA（实验与合规并重）

- 部分项目将房产份额或收益权映射为 721/合规证券型代币（因辖区而异）。  
- **商业要点**：链上 token 只是登记层，法律效力在链下合同与监管牌照。

### 2.6 品牌会员与忠诚度（Web2 升级）

- **Starbucks Odyssey（已调整战略，但模式具代表性）**：消费行为与 NFT 勋章结合。  
- **耐克 .SWOOSH / RTFKT**：虚拟鞋与实体权益捆绑，721/1155 混合使用。

## 3. 收入模型拆解

```text
一级发售（Mint 收入）
    ↓
持有者使用权益（社区、游戏、线下活动）
    ↓
二级市场交易 → 平台手续费 + 创作者版税
    ↓
IP 授权、联名、续费会员（链下合同为主）
```

对产品经理：要算清 **LTV** 来自「炒作转手」还是「持续权益」，两者运营策略完全不同。

## 4. 与课内 Demo 的对应

| Demo | 商业映射 |
|------|----------|
| `mint(to, uri)` | 发售会员证/藏品，URI 指向元数据（图片、权益说明） |
| `tokenURI` | 钱包、OpenSea 展示名称与图片的来源 |
| `safeTransferFrom` | 防止 NFT 误转入无法处理的合约（减少客诉） |

---

## 5. 商业风险

- **版税可执行性下降**：部分市场默认可选版税，创作者收入模型需重新设计。  
- **炒作与证券定性**：如何宣传「投资回报率」涉及合规红线。  
- **元数据中心化**：`tokenURI` 若指向公司服务器，关停即「图片消失」→ 需 IPFS/链上存储策略。  
- **仿盘与钓鱼**：同名假合集，品牌需官方认证合集地址。

---

## 6. 何时用 721

| 场景 | 建议 |
|------|------|
| 每张会员卡/门票编号唯一 | 721 |
| 一万张完全相同的兑换券 | 20 或 1155 某 id |
| 游戏多种道具、批量空投 | 常选 1155 |
