# ERC-1155 商业案例讲解

**一句话**：**一个合约、多种商品 SKU**——金币可以成千上万份，稀有装备可以只有 1 份，还能 **批量转账、批量空投**。游戏、票务、品牌周边最吃这一套，能显著降低合约部署与运营 gas。

配套演示：`erc-demo/erc1155/DemoERC1155.sol`（`ID_GOLD` / `ID_CARD` 类比游戏币与稀有卡）。

---

## 1. 解决什么商业问题

| 商业诉求 | ERC-1155 如何满足 |
|----------|-------------------|
| 多 SKU 统一结算 | 同一合约内用 `id` 区分商品，库存与余额分开记账 |
| 批量运营 | `mintBatch`、`safeBatchTransferFrom` 适合空投、赛季结算 |
| 半同质化 | 同一 `id` 下每个单位可互换（如金币），不同 `id` 互不替代 |
| 降低发行成本 | 比「每种道具发一个 ERC-20 合约」省部署与集成 |

---

## 2. 成熟商业案例

### 2.1 链游与虚拟道具

- **Gods Unchained** 等卡牌游戏  
  - **模式**：卡牌、卡包、/cosmos 相关资产用 1155 管理；可交易、可合成。  
  - **收入**：卡包销售、二级市场、赛季通行证。  
- **Sky Mavis（Axie Infinity）生态**（历史上大量使用 1155 类设计管理宠物部件、土地等）  
  - **启示**：游戏内大量同质化道具 + 少量稀有物，适合 1155 而非每张卡一个 721。

### 2.2 品牌与大规模 C 端空投

- **Reddit Collectible Avatars**  
  - **模式**：数百万用户领取不同款式头像；1155 便于 **分批铸造、批量分发**。  
  - **商业目标**：拉新、社区身份、后续品牌合作——不强调每张 721 的天价炒作。

### 2.3 数字时尚与限量周边

- **Nike / RTFKT** 等  
  - 常混合 721（独一无二联名款）与 1155（多副本虚拟鞋、材料）。  
  - **模式**：虚拟商品 + 实体兑换码；二级市场与品牌官网闭环。

### 2.4 票务与通行证（批量场景）

- 大型活动 **通票 / 等级票**（普通席、VIP）可用不同 `id` 表示；  
- 入场核销系统扫 `id` + 余额或持有关系；  
- 与 721「一票一号」相比，1155 更适合 **同等级大量座位**。

### 2.5 开放创作者平台

- **Zora** 等支持 **Multi-edition**（固定供应量多份拷贝）  
  - **商业模式**：创作者发限量版印刷品式 NFT，粉丝价低、量大；平台抽成。  
  - 1155 的「同 id 多份」天然对应 **限量版数 N**。

### 2.6 供应链与防伪（试点）

- 企业用 `id` 表示 SKU 批次，链上记录流转（需链下流程配合）；  
- 商业价值在 **溯源与打假**，而非代币炒作。

## 3. 与 ERC-20 / 721 的商业选型

| 需求 | 更优标准 | 原因 |
|------|----------|------|
| 平台只有一种积分 | ERC-20 | 最简单 |
| 明星单品拍卖、PFP | ERC-721 | 每件唯一，叙事强 |
| 游戏多道具 + 赛季空投 | ERC-1155 | 批量、多 SKU |
| 限量版 100 份完全相同版画 | ERC-1155 单 id 供应量 100 | 比 100 个 721 便宜 |

---

## 4. 收入与运营模型

```text
道具销售（mint 收入）
    + 赛季通行证（捆绑多种 id）
    + 二级市场版税/手续费
    + 游戏内消耗（sink）销毁 id 余额 → 经济循环
```

**关键指标**：日活、ARPU、道具销毁率、空投领取率、二手流转率。

| Demo | 商业映射 |

| `ID_GOLD` + `mintGold` | 游戏金币、平台积分（可大量） |

| `mintBatch` | 赛季结算一次发多种奖励 |
| `safeBatchTransferFrom` | 公会仓库批量发装备 |

---

## 6. 商业风险

- **元数据与 id 设计混乱**：运营后期 `id` 爆炸，前端难以维护 → 需 SKU 规划表。  
- **游戏经济通胀**：金币 id 滥发贬值 → 需消耗场景与上限。  
- **监管**：若 1155 代表证券型收益权，仍可能涉证券法。  
- **用户体验**：比 20 复杂，钱包展示需定制（显示「金币 x1000」而非裸 id）。
